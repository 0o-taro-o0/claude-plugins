# 指摘の書式

レビュー役がプルリクエストへ投稿するときに使う。指摘は1件ずつ別のコメントに分ける。

    [差し戻し] <対象のファイルと行>
    <何が問題か。1〜3行>
    <そう判断した根拠。実際に確かめた内容を書く>

## 区分

| 区分 | 該当するもの | 扱い |
|---|---|---|
| 差し戻し | 明確な不具合、検証の不備、`CLAUDE.md`「判断を仰ぐこと」に該当するもの | 対応するまでマージしない |
| 推奨 | 直したほうがよいが、直さなくても動くもの | 実装役が判断する。直さない場合は GitHub Issue に起票する |
| 任意 | 好みの範囲にとどまるもの | 対応しなくてよい |

## 注意事項

- 推測で指摘しない。実際に確かめた内容を根拠として書く。
- 実装役の説明ではなく、変更そのものを見て判断する。
- 文書の修正では、修正の跡が残っていないかを見る(その文書が最初からこう書かれていた
  として、不自然な点がないか)。
