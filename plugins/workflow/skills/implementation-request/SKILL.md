# 実装依頼

指揮役が実装役へ作業を渡すときに使う。

    目的: <なぜこの作業が必要か。1〜3行>
    範囲: <行うこと>
    範囲外: <行わないこと>
    完了条件: <何をもって完了とするか>
    参考: <規定文書の該当箇所、関連するプルリクエストや GitHub Issue の番号>

## 注意事項

- 範囲外は必ず書く。書かないと、周辺の改善にまで手が広がる。
- 参考には場所を示すだけでなく、判断に必要な事実を依頼文そのものに書き写す。
